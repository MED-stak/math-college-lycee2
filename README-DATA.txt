ORGANISATION DES DONNÉES — MATH POUR COLLÈGE ET LYCÉE

Chaque niveau dispose de fichiers indépendants pour les 4 catégories et les 2 formats :
  data/<Catégorie>/<PDF ou Videos>/<CODE>.js

Catégories : Cours, Exercices, Devoirs, Examens.
Formats : PDF, Videos.

LYCÉE — NIVEAUX CONFIGURÉS
  TC       — Tronc Commun Sciences
  TCL      — Tronc Commun Lettres
  1BACSE   — 1BAC Sciences Expérimentales
  1BACSM   — 1BAC Sciences Mathématiques
  1BACL    — 1BAC Lettres
  2BACSVTPC — 2BAC SVT et PC
  2BACL    — 2BAC Lettres
  2BACSM   — 2BAC Mathématiques

Les titres des leçons fournis ont été ajoutés dans les fichiers des huit niveaux du lycée, dans les quatre catégories et les deux formats. Les champs url restent vides : ajoutez-y vos liens Google Drive, YouTube ou autres.

Exemple : data/Cours/PDF/TCL.js ou data/Examens/Videos/2BACSM.js

Pour ajouter ou corriger un titre, modifiez le champ title dans le fichier correspondant. Les fichiers sont indépendants; une modification dans un fichier ne change pas les autres fichiers.
